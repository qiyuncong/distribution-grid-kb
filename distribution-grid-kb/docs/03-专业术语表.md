# 输配电专业术语表

## 一、电压等级类

### 1. 特高压（UHV）
- 定义：交流 1000kV 及以上、直流 ±800kV 及以上的电压等级
- 用途：大容量、远距离输电，跨区域电网互联
- 特点：输电容量大、损耗低、走廊窄

### 2. 超高压（EHV）
- 定义：交流 330kV～750kV 电压等级
- 用途：区域电网主干网架、大型输电通道

### 3. 高压（HV）
- 定义：35kV～220kV 电压等级
- 用途：城市电网主干、地区供电
- 110kV：城市最常用的输电/配电衔接电压等级

### 4. 中压（MV）
- 定义：1kV～35kV 电压等级
- 10kV：配电网最常用电压等级，直接向用户供电
- 20kV：部分城市（苏州、苏州工业园）采用，供电半径更大

### 5. 低压（LV）
- 定义：1kV 以下电压等级
- 380V/220V：三相四线制，最终用户用电电压

## 二、电网结构类

### 6. 配电网
- 定义：从输电网接受电能，分配给终端用户的电力网络
- 组成：配电变电站、配电线路、配电变压器、开关设备
- 特点：电压等级较低、供电距离短、点多面广

### 7. 输电网
- 定义：高压、超高压输电线路组成的骨架网络
- 功能：将大型发电厂的电能输送到负荷中心
- 特点：电压高、容量大、距离远

### 8. 环网
- 定义：由两回或多回线路构成环形供电网络
- 优点：供电可靠性高，任一段线路故障可转供
- 缺点：继电保护配合复杂

### 9. 放射式电网
- 定义：从一个电源点单方向放射状供电
- 优点：接线简单、投资省
- 缺点：可靠性差，线路末端故障影响全线

### 10. 手拉手供电
- 定义：两条配电线路通过联络开关连接，形成开闭所之间的手拉手结构
- 作用：故障时可通过联络开关转供，缩小停电范围

## 三、设备类

### 11. 配电变压器（配变）
- 定义：将 10kV 降为 380V/220V 的降压变压器
- 安装位置：柱上、台架、配电室、箱式变电站
- 常用容量：100kVA、200kVA、400kVA、630kVA

### 12. 柱上断路器
- 定义：安装在电杆上的高压开关设备
- 功能：分合线路负荷电流，故障时由保护控制跳闸
- 类型：真空断路器、SF6 断路器、永磁断路器

### 13. 环网柜
- 定义：用于环网供电的开关设备组合柜
- 结构：负荷开关 + 熔断器组合
- 特点：结构紧凑、可靠性高、广泛用于小区和工业区

### 14. 电缆分接箱
- 定义：用于电缆线路分支、连接的户外设备
- 类型：普通分接箱、带开关分接箱
- 用途：电缆线路 T 接分支

### 15. 避雷器
- 定义：限制雷电过电压和操作过电压的保护设备
- 类型：氧化锌避雷器（无间隙）
- 安装位置：变电站母线、线路杆塔、变压器高压侧

## 四、运行方式类

### 16. 小电流接地系统
- 定义：中性点不接地或经消弧线圈接地的系统
- 我国 6kV～66kV 配电网普遍采用
- 特点：单相接地时可继续运行 1～2 小时，供电可靠性高

### 17. 大电流接地系统
- 定义：中性点直接接地的系统
- 我国 110kV 及以上电网采用
- 特点：单相接地即跳闸，故障定位快

### 18. 消弧线圈
- 定义：接在变压器中性点的可调电感线圈
- 作用：补偿单相接地时的电容电流，减少接地电弧
- 原理：电感电流抵消电容电流，使接地点电流减小

### 19. 重合闸
- 定义：线路跳闸后自动重新合闸的装置
- 作用：瞬时性故障（雷击、鸟兽）可自动恢复供电
- 成功率：架空线路约 70%～90%
- 电缆线路一般不投重合闸

### 20. 馈线自动化（FA）
- 定义：利用自动化设备实现配电网故障定位、隔离和恢复供电
- 组成：FTU（馈线终端单元）、DTU（站所终端单元）、通信网络
- 效果：故障停电时间从小时级缩短到分钟级

## 五、可靠性指标类

### 21. 供电可靠率（RS-1）
- 定义：用户全年不停电时间的百分比
```
供电可靠率 = (8760 - 用户平均停电时间) / 8760 × 100%
```
- 城市核心区目标：99.99% 以上（年停电时间 < 53 分钟）

### 22. 户均停电时间
- 定义：平均每个用户每年的停电小时数
- 衡量配电网可靠性的核心指标

### 23. 线损率
- 定义：线路损耗电量占供电量的百分比
- 国家平均线损率约 6% 左右
- 目标：逐年下降，达到国际先进水平
