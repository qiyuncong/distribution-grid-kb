# 配电线路故障分析与处理

## 一、配电网故障分类与统计

配电网故障按性质可分为两大类：

### 1. 横向故障（短路故障）
- **单相接地故障**：发生概率最高，约占配电网故障总数的 70%～85%
  - 常见于架空线路、树木碰触、绝缘子击穿
  - 在小电流接地系统中，可继续运行 1～2 小时，但需尽快查找故障点
- **两相短路故障**：约占故障总数的 8%～10%
- **两相接地故障**：约占故障总数的 5%～8%
- **三相短路故障**：概率最低（约 2%～5%），但危害最严重

### 2. 纵向故障（断线故障）
- 一相断线、两相断线
- 概率较低，但会造成非全相运行

## 二、10kV 架空线路常见故障原因

### 1. 雷击故障
- 现象：雷击后绝缘子闪络、线路跳闸，重合闸成功概率较高
- 多发季节：雷雨季节（6～9 月）
- 多发地段：山区、高地、土壤电阻率高的杆塔
- 处理：检查避雷器动作计数器、更换击穿的绝缘子

### 2. 外力破坏
- 树木碰线：树线距离不足，刮风时导线与树枝接触放电
- 施工机械碰线：吊车、挖掘机碰触线路
- 鸟巢异物：鸟类筑巢材料（铁丝、树枝）搭接导线
- 处理：清理树障、施工保护区设立警示、拆除鸟巢

### 3. 设备老化
- 绝缘子老化击穿：运行年限超过 15 年的线路
- 柱上开关机构故障：操作机构卡涩、SF6 气体泄漏
- 电缆头故障：中间接头或终端头绝缘老化
- 处理：定期预防性试验、更换老旧设备

### 4. 用户侧故障越级
- 用户内部故障，其出线开关未动作，导致变电站出线开关跳闸
- 处理：检查用户侧保护定值、加强用户设备巡检

## 三、故障排查步骤

### 步骤一：故障信息收集
- 调取变电站自动化系统：记录故障时间、跳闸相别、重合闸动作情况
- 查看故障录波：分析故障电流、电压波形
- 询问调度：故障时天气情况、有无检修作业

### 步骤二：分段巡视
- 从变电站出线开始，沿线路逐基杆塔巡视
- 重点检查：耐张段、转角杆、分支杆、电缆头
- 夜间可通过红外测温、夜间熄灯巡视查找放电点

### 步骤三：故障定位
- 分支线分段开关：通过拉合分段开关，缩小故障区段
- 故障指示器：架空线路上的短路接地故障指示器翻牌报警
- 电缆故障测距：用电桥法、脉冲反射法定位电缆故障点

### 步骤四：故障处理
- 隔离故障区段：拉开故障段两侧开关
- 转供电：通过联络开关恢复非故障段供电
- 修复：更换损坏设备、处理缺陷
- 恢复送电：确认安全后，逐级恢复供电

## 四、典型故障处理案例

### 案例 1：10kV 线路单相接地选线
- 现象：10kV 母线一相电压降低，另外两相电压升高，母线接地告警
- 处理：
  1. 调度按拉路顺序依次拉合各出线开关
  2. 拉某条线路时接地信号消失，即为故障线路
  3. 通知线路班组巡线查找故障点
  4. 找到故障点后停电处理

### 案例 2：电缆终端头爆炸
- 现象：电缆头爆炸声、开关跳闸、现场有焦糊味
- 处理：
  1. 立即拉开故障电缆两端开关
  2. 做好安全措施，防止他人误入
  3. 拆除故障终端头，重新制作冷缩/热缩终端头
  4. 做耐压试验合格后送电
