# 输配电常用计算方法

## 一、短路电流计算

### 1. 计算目的
- 选择电气设备：断路器、隔离开关、母线、互感器的额定开断电流和动热稳定
- 整定继电保护：确定保护动作电流和动作时间
- 设计接线方案：确定限流措施、限制短路容量

### 2. 基本公式

#### 三相短路电流周期分量
```
Ik = Uc / (√3 × Zs)
```
其中：
- Ik：三相短路电流周期分量有效值（kA）
- Uc：平均线电压（kV），10kV 系统取 10.5kV
- Zs：系统总阻抗（Ω），包括系统阻抗 + 变压器阻抗 + 线路阻抗

#### 短路容量
```
Sk = √3 × Uc × Ik
```
- Sk：短路容量（MVA）
- 用于校验断路器遮断容量

#### 冲击电流（短路冲击电流）
```
ish = 2.55 × Ik （10kV 系统，冲击系数取 1.8）
```
- ish：短路冲击电流峰值（kA）
- 用于校验设备动稳定

### 3. 常用元件阻抗计算

#### 变压器阻抗（按短路电压百分比）
```
Zt = Uk% × Un² / Sn
```
- Zt：变压器阻抗（Ω）
- Uk%：短路电压百分比（如 10kV 变压器取 4.5%）
- Un：额定电压（kV）
- Sn：额定容量（MVA）

#### 线路阻抗（单位长度阻抗）
```
Z_line = R0 × L + jX0 × L
```
- 10kV 架空线路：R0 ≈ 0.65 Ω/km，X0 ≈ 0.35 Ω/km
- 10kV 电缆线路：R0 ≈ 0.2 Ω/km，X0 ≈ 0.08 Ω/km

### 4. 计算步骤
1. 画等值电路图，标出各元件阻抗
2. 选基准容量（一般取 Sj = 100 MVA）
3. 计算各元件标幺值
4. 化简网络，求短路点总阻抗
5. 计算短路电流、短路容量、冲击电流

## 二、配电网线损计算

### 1. 线损分类
- 技术线损：电流通过电阻产生的损耗，可理论计算
- 管理线损：计量误差、窃电、管理不善造成的损耗

### 2. 线损率计算公式
```
线损率 = (供电量 - 售电量) / 供电量 × 100%
```

### 3. 理论计算方法（均方电流法）
```
ΔA = 3 × Ijf² × R × t × 10⁻³
```
- ΔA：线路损耗电量（kWh）
- Ijf：均方电流（A）
- R：线路电阻（Ω）
- t：运行时间（h）

### 4. 降低线损的措施
- 高压深入负荷中心，缩短供电半径
- 合理配置无功补偿，提高功率因数
- 变压器经济运行，避免轻载或过载
- 改造老旧线路，增大导线截面
- 三相负荷平衡，减少中性线损耗

## 三、负荷计算

### 1. 计算负荷（需要系数法）
```
Pjs = Kx × Pe
```
- Pjs：计算有功负荷（kW）
- Kx：需要系数（照明取 0.8～1.0，动力取 0.4～0.7）
- Pe：设备总容量（kW）

### 2. 视在功率与计算电流
```
Sjs = Pjs / cosφ
Ijs = Sjs / (√3 × Un)
```
- cosφ：功率因数，补偿后取 0.95 以上

### 3. 变压器容量选择
```
Sn ≥ Sjs / 负载率
```
- 经济负载率取 0.6～0.8
- 预留 15%～20% 负荷发展裕度

## 四、电压损失计算

### 1. 线路电压损失公式
```
ΔU% = (P × R + Q × X) / (Un × 10)
```
- ΔU%：电压损失百分数
- P：有功功率（kW）
- Q：无功功率（kvar）
- R、X：线路电阻、电抗（Ω）
- Un：额定电压（kV）

### 2. 电压质量标准
- 10kV 配电线路：电压偏差不超过 ±7%
- 220V 低压用户：+7% ～ -10%
