# 输配电专业知识库仓库

大学输配电专业 Dify 智能体实验专用知识库，包含故障分析、计算方法、专业术语、技术导则四大类文档。

## 仓库结构

```
distribution-grid-kb/
├── docs/
│   ├── 01-配电故障处理.md      # 故障分析类知识
│   ├── 02-输配电计算方法.md   # 计算类知识
│   ├── 03-专业术语表.md       # 术语查询类知识
│   └── 04-配电网技术导则摘要.md # 技术规范类知识
├── dify_external_kb.py        # Dify外部知识库API服务脚本
└── README.md
```

## 使用方法

### 方式一：直接上传到Dify内置知识库（推荐，最简单）

1. 点仓库页面绿色「Code」→「Download ZIP」
2. 解压后，把 `docs/` 文件夹里的 4 个 `.md` 文件
3. 打开 Dify → 知识库 → 创建知识库 → 上传这 4 个文件
4. 等待索引完成，即可在应用中使用

### 方式二：作为外部知识库API连接Dify

1. 把本仓库上传到你的GitHub账号
2. 修改 `dify_external_kb.py` 里的 `GITHUB_RAW_BASE` 为你的仓库地址
3. 安装依赖：`pip install fastapi uvicorn requests`
4. 运行服务：`python dify_external_kb.py`
5. 在Dify中添加外部知识库API，地址填你电脑的IP:8000

## 文档内容概览

| 文档 | 内容 | 对应智能体分支 |
|---|---|---|
| 01-配电故障处理 | 故障分类、跳闸原因、排查步骤、处理案例 | FAULT 故障分析分支 |
| 02-输配电计算方法 | 短路电流、线损、负荷、电压损失计算 | CALC 计算分支 |
| 03-专业术语表 | 电压等级、设备、运行方式、可靠性术语 | QUERY 查询分支 |
| 04-配电网技术导则摘要 | 供电区域划分、网架结构、设备选型 | 通用规范参考 |
